# Stalwart + OpenSMTPD Outbound Relay Architecture

## 1. Overview
Secure, open-source, ultra-lightweight email hosting.

```
Internet ──:25──→ GCP FreeBSD VM (public MX: 34.172.72.51)
                    │
                    │ Jail "mail" (Stalwart)
                    │ outbound mail via :587 (authenticated)
                    ▼
               Clouding.io VPS (hidden outbound relay: 93.189.88.176)
                    │
                    │ :25 → internet
                    ▼
               Gmail/Yahoo/etc.
```

- **GCP FreeBSD VM (`wou` / 34.172.72.51)**: Receives inbound on port 25. Stalwart runs in a lightweight thin jail. Outbound is relayed to Clouding.io on port 587.
- **Clouding.io VPS (93.189.88.176)**: Pure outbound relay running OpenSMTPD on port 587. IP-restricted to ONLY accept mail from GCP. Delivers directly on port 25.

## 2. Compilation (Local)
Cross-compile a minimal SQLite-only binary with zero extra bloat:
```bash
rustup target add x86_64-unknown-freebsd
cargo zigbuild --target x86_64-unknown-freebsd --release -p stalwart --no-default-features --features "sqlite"
```
The binary is generated at `target/x86_64-unknown-freebsd/release/stalwart`.

## 3. GCP Mail Jail Setup
On the GCP FreeBSD host:
```bash
# 1. Clone base jail
sudo zfs clone zroot/jails/base@clean zroot/jails/mail

# 2. Add definition to /etc/jail.conf
sudo tee -a /etc/jail.conf << "EOF"
mail {
  host.hostname = "mail.worldofunreal.com";
  path = /zroot/jails/mail;
}
EOF

# 3. Create directories and copy binary inside the jail
sudo mkdir -p /zroot/jails/mail/usr/local/bin /zroot/jails/mail/usr/local/etc/stalwart /zroot/jails/mail/var/db/stalwart
sudo cp /home/bizkit/stalwart /zroot/jails/mail/usr/local/bin/stalwart
sudo chmod 755 /zroot/jails/mail/usr/local/bin/stalwart

# 4. Create compatibility symlink for FreeBSD 15 libutil
sudo ln -s /lib/libutil.so.10 /zroot/jails/mail/lib/libutil.so.9

# 5. Add rc.d script inside jail (copy rc.d-stalwart)
sudo cp /home/bizkit/rc.d-stalwart /zroot/jails/mail/usr/local/etc/rc.d/stalwart
sudo chmod 755 /zroot/jails/mail/usr/local/etc/rc.d/stalwart

# 6. Enable and start service
sudo jexec mail sysrc stalwart_enable=YES
sudo service jail restart mail
sudo jexec mail service stalwart start
```

## 4. Clouding.io Relay Setup
On the Clouding.io FreeBSD host:
```bash
# 1. Install OpenSMTPD
pkg install -y opensmtpd

# 2. Configure /usr/local/etc/mail/smtpd.conf (restrict to GCP IP)
table allowed_ips { 34.172.72.51 }
listen on 0.0.0.0 port 587
action "relay" relay
match from src <allowed_ips> for any action "relay"

# 3. Start service
sysrc smtpd_enable=YES
service smtpd start
```
Enable the **Tráfico SMTP de salida** (outbound SMTP) toggle in the Clouding.io web dashboard.

## 5. DNS (Cloudflare)
- **A Record**: Name: `mail.worldofunreal.com` | Target: `34.172.72.51` | Proxy: DNS only (grey cloud)
- **MX Record**: Name: `@` | Target: `mail.worldofunreal.com` | Priority: 10
- **TXT Record (SPF)**: `v=spf1 mx ~all`
- **TXT Record (DMARC)**: Name: `_dmarc` | Value: `v=DMARC1; p=quarantine;`
- **TXT Record (DKIM)**: (Copy public key generated by Stalwart under the DKIM configuration on first-run wizard)
