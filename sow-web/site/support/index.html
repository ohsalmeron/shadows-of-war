Game support

For connection issues, account problems, or a bug report, email info@shadowsofwar.io. Include your browser, device, approximate time, and a short description of what happened.

Security reports

Please do not publish a security vulnerability in a public issue. Send it privately to info@shadowsofwar.io. We aim to acknowledge reports within 48 hours.
